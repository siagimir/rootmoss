Your AI keeps forgetting you.
Your files don't.

Rootmoss is a plain folder of Markdown files — your profile, your decisions, your notes — with one instruction file at the top that your agent reads first. Teach it once, and every new chat starts already knowing who you are and what you've decided. The folder lives on your own disk, and it stays yours. Nothing is ever deleted — outdated notes get marked, not lost.

Works with OpenCode — terminal, desktop app or web — or any agent that reads AGENTS.md. Open it like any folder — Finder is enough. No account. No subscription. No company holding your data.

Why it matters

What changes for you

It's just a folder. What changes is every conversation that comes after.

01

You stop repeating yourself

Your agent opens every chat already knowing your profile, what you're working on and what you learned last time — so you can ask the real question instead of re-explaining yourself.

02

Your memory outlives your tools

Change the model, the tool, or the company behind it. Your history is plain files you already own — nothing to export, nothing to migrate, nobody to ask.

03

Nothing gets thrown away

When something you wrote stops being true, your AI marks it outdated instead of deleting it. Your notes can get messy — they can't disappear.

04

Every chat makes the next one better

You don't have to save whole chats. The few things worth remembering — a decision, a lesson, a preference — get written down and come back to you exactly when they're useful.

05

Nothing leaves your disk

No account, no sync service, no company sitting between you and your own memory. A plain folder is all it takes. Want version history? Add a private git repo later.

Under the hood

How it works

Nothing to run, nothing to host. One instruction file at the top of the folder, your notes underneath.

  1. You clone the template

    You get a folder: AGENTS.md (the rules your agent follows), USER.md (a short profile of you), six memory/ folders for different kinds of knowledge, and one folder for each area of your life.

  2. Your agent reads the rules first

    Before you type a word, it reads the instruction file, your profile, and the folder for whatever you're working on — so it starts out informed instead of blank.

  3. It writes back, briefly

    After a real conversation it saves a short note about what matters — never whole transcripts — and marks older notes outdated instead of deleting them. Next time, it reads them back. 

rootmoss/
├── AGENTS.md            # the rules your agent reads first
├── USER.md              # a short profile of you
├── FIRST-TIME-HERE.md   # the guided tour
├── memory/              # everything worth remembering
│   ├── facts/          # what is true
│   ├── preferences/    # how you like things
│   ├── decisions/      # choices you made
│   ├── assumptions/     # guesses, marked as guesses
│   ├── lessons/         # what didn't work
│   └── context/         # what's true right now
├── topics/              # one folder per subject
│   └── plants/          # fictional demo, delete it
└── inbox/               # chats that fit nowhere yet

Open it like any folder — or ask your AI to explain any line. Obsidian or Zed if you want a nicer view (optional). It's just files.

Get started

Up and running in about 15 minutes

Two ways in: run it yourself, or have someone set it up once for you. Either way, the first run is an interview — your agent asks before it changes anything.

Path A — I'll set it up myself

STEP 01

Create your copy

Click Use this template and make your own private repo. Your copy is a snapshot: it never changes behind your back. Updates come only when you choose to pull them.

STEP 02

Get OpenCode

Two options: the desktop app — download, install, no terminal — or one line in the terminal (brew, npm or curl). Then clone your repo.

STEP 03

Start it inside the folder

Open your Rootmoss folder in the desktop app, or run opencode from the folder in a terminal. Any agent that reads AGENTS.md works just as well.

STEP 04

Paste the first message

One message sets up your profile and proposes your first topic. Then follow the tour.

Path B — set it up once, for me

No terminal, no install — just a browser

OpenCode also runs as a web app. Someone technical sets it up once on a machine you can reach — about 15 minutes — and after that you only open a bookmark. The setup happens once; the daily use is just a conversation. This is how family members usually start.
