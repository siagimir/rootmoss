# personal-os

**Status**: Active (template v0)

## Why this topic exists

This is the **meta topic** — the living design space for the knowledge
system itself. Anything about how the tree works belongs here: memory
policy, skills, `AGENTS.md` rules, structure, lifecycle conventions.

Life subjects (coffee, health, work, …) get their **own** topics under
`topics/` — not this one.

## Current status

- **This repo started as the Rootmoss template** (history-free scaffold,
  MIT). It is your copy now — treat it as yours.
- Core: typed memory (six types), lifecycle (`active` / `superseded` /
  `closed`), topic routing, entity dossiers, inbox staging, untrusted
  research contract — see `AGENTS.md` + `FIRST-TIME-HERE.md`.
- Skills shipped: `start-topic`, `extract-memory`, `repo-audit`,
  `markdown-style`, `untrusted-research`.
- The demo topic `topics/plants/` is fictional — delete it after your
  first look.
- Experimental: report friction as issues; adapt rules to your taste —
  this tree is yours to modify.
