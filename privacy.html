Privacy

Last updated 27 October 2026

The short version: this page does not know who you are, does not want to find out, and does not collect anything about you.

What this page collects

Nothing. There are:

  • no cookies — so there is nothing to consent to,
  • no analytics — no Google Analytics, no page counters,
  • no trackers — no advertising, no social-media pixels,
  • no forms — no sign-up, no newsletter, no email capture.

The page is plain HTML that your browser downloads and displays. Nothing is sent back anywhere.

Where the page is hosted

Rootmoss is served by GitHub Pages. Like any web host, GitHub necessarily sees the technical basics — your IP address, your browser type and the time of your request — in order to deliver the files and to protect its service from abuse. That data is handled by GitHub, under GitHub's own privacy statement.

Rootmoss itself has no server of its own, no database, and no access to those logs.

Links to other sites

This page links to GitHub. OpenCode and Obsidian are mentioned by name only — nothing is embedded here. If you follow a GitHub link, you leave this page and GitHub's own privacy policy applies.

The software itself

Rootmoss is a folder of Markdown files you run on your own computer. Your notes, your profile and your memories never leave your machine unless you put them somewhere — a private git repository of your own, for instance. The software does not phone home, and there is no Rootmoss server for it to talk to.

Choosing where your files live — and any backup or encryption you apply — is your responsibility; Rootmoss has no server that could do it for you.

If this changes

If this page ever starts doing something more, this notice will be updated before it happens and the date at the top will change. As it stands, there is nothing to update.

Getting in touch

Questions? Open an issue on the GitHub repository — that is also public, so please don't post anything private there.
