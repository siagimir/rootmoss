# context/

Temporary or situational background — what is going on **right now**.

- Expires by nature: roll it forward when the situation changes, and
  mark old files `superseded` or `closed`
- Session-critical state belongs in the active `topic.md`, not here

Filenames: `YYYY-MM-DD-short-kebab.md` — with the standard memory header
(see `AGENTS.md`).
