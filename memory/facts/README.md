# facts/

Objectively true (or currently strongly believed true) statements about
the world or the user.

Examples:

- Hardware the user owns
- Confirmed constraints
- Verified information
- Identity / language / location detail

**vs USER.md**: `USER.md` holds only the thin key profile. Put atomic
detail here.

Do **not** put preferences, decisions, or temporary context here.

Filenames: `YYYY-MM-DD-short-kebab.md` — with the standard memory header
(see `AGENTS.md`).
